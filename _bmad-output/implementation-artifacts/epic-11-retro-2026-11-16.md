- **Bench pages gated the build.** 11.1 (dispersion), 11.2 (reach), 11.3 (arc — and it let Eric shelve it cheaply), 11.8 (candidates). The 11.6 rain page locked up and was dropped, but the rulings were taken on it first.
- **Two Epic 10 agreements held completely.** Numbers at PR time — 11.7 / 11.8 crossed and were renumbered cleanly at merge; no PR opened on an unjudged look.
- **The review gate earned its keep:** ~7 information leaks caught before ship (aim seed recoverable, class from a blip, linkable handles, unsent smoke charged, rain grid leaking class); Codex alone caught the reach-from-station mismatch (11.1) and a hit drawn as a miss (233). The six-exception perception rule held.
- **fogSmoke rewritten as a scripted scenario** (11.6), first-try green.
- **After 11.2, staging never broke again** — `tickCost.mjs` / `glBudget.mjs` before any reach or render PR became the rule and was followed.

## 3. Challenges

- **11.2 broke staging.** ~9× reach took a 16-hull tick 2.7 → 47.6 ms (budget 50), sized a GPU mask 16,384² (32,768² at 2×), and a fog texture destroyed while still a mask froze the client. Three follow-up cycles; two of them fixed real but different bugs before the frozen client was found. Eric: *"Fuck you and your assumptions. Do better."* Cause: a reach-scaling change shipped without a full-match cost measurement or a GPU budget check.
- **The epic delivered something other than its title.** The pillar was *"a marine radar simulator that happens to have a naval battle royale attached"*; its radar heart — the arc (11.3), the operated set and ghosts (11.4), the splash return (11.5) — is shelved or deferred. Ten of seventeen cycles went to guns, shells and torpedoes, following what played well. Not a fault; the plan should say so when the next radar work is picked up.
- **Rulings overturned inside the epic:** 11.1's dispersion dials and flat blast replaced at 231; the secondaries' hit rule changed twice (231, 233); 11.2's plain-hull sight tier removed by 11.6; 11.1's preview look re-cut twice; 11.7 midpoint → random; torpedo reload cuts rejected. Iowa ARMOR 95 was ruled unmeasured (the arm ran 100).
- **Record drift:** PR #359 **overwrote the append-only amendments file** (1–19 deleted; 19 existed only in git) — restored by this retro; row 11-11 left at `review` after PR #356 merged; `CHANGELOG.md` stops at 0.19.20; cycle 231 has no spec file; `batch-sim-evidence-2026-11-15.md` lives only on open PR #351; the gds `next_expected` still described 11-2.
- **Machine load:** 11.7's `npm run check` timed out at 40 min at load ~280.

## 4. Key Insights

1. **Measure the whole match before a scale change merges.** A local green gate says nothing about a 9× reach; staging said it for us.
2. **Follow the fun, and write it down.** Eric played 11.3 and kept the old paints; the epic's energy moved to weapons. Shelving was cheap because the bench page came first.
3. **An append-only file needs a rule an agent can check.** A diff with deletions in an amendment file is the whole test.
4. **The merge stamp still slips** — one row this epic (eleven, three, now one). Improving, not solved.
