2. **Zero high-severity review findings — a first.** Finding severity tracked risk honestly: the deepest catch was Codex's forward-secrecy trace in 3-1 (ring 1's revealed geometry disclosed two raw outputs of one 32-bit stream, brute-forceable offline to precompute all future rings → per-ring independent server-private seed streams, forward-secrecy pins). Cross-model review earning unique catches for the fourth epic running.
3. **"Fix the instrument, not the game" (amendment 25) is the epistemics headline.** The endgame campaign's cap-outs were probe-diagnosed as island-beaching permalocks of the forward-only *pilots* (humans carry full astern; the game has no permalock). Eric ruled: teach the instrument seamanship, rerun everything, touch no game dial. Final: 50/50 resolved, zero mutual-avoidance failures at any iteration — the geometric no-stalemate claim never failed; only the instrument did.
4. **The no-stalemate bar is GEOMETRIC (amendment 24)** — no forcing mechanic exists. The Endgame Guarantee is a design theorem with a measured proof, and the derivation doctrine makes it durable: radar = 2×sight and terminal ring = 2×sight by two independent derivations, bound by shared constraint tests so a one-sided retune fails the build. Retuning truesight now moves gun range, star-shell flare, radar paint, and the endgame ring together.
5. **The in-run screenshot design gate (3-2, amendment 18) closed Epic 2's standing "visual stories ship without a browser pass" gap** for the epic's biggest visual story: 8 live captures from a self-booted scratch stack (3 states × 3 zooms, production timeline), ratified on sight. 6. **Client-only discipline paid out:** 3-3's investigation found every chrome-bar input already on the wire — the epic's most visible feature shipped with zero wire change; 3-4's production diff was one line. Two of four stories left shared/server byte-untouched.
7. **The attention seam grew the right way ahead of schedule** — pure module in 3-2 (first consumer of the EXPERIENCE.md tier table), second Tier-2 consumer in 3-3, both fully unit-tested, before Story 4-8 generalizes the system.
8. **Interstitial cycles absorbed live feedback same-day** (join-window, tracking-mine fix + aim previews, star-shell preview, continuous readout) without destabilizing the story pipeline — the rule-up-front + correct-on-sight model operating at speed.

## Challenges & Growth Areas

1. **Instrument fidelity is the new house bug family** (Epic 2's was same-tick concurrency): pilot seamanship gaps read as game stalemates; the BB's 50% instrument endgame share is plausibly inflated (no kiting/torpedo/mine play — the light hulls' designed styles); fogSmoke's flake was smoke bookkeeping, not perception. The amendment-25 v2 paper-trail finding (v2 exceeded the ruling's recorded text; surfaced honestly but post-hoc) belongs to the same family. Standing posture: evidence instruments get the same skepticism as production code, and instrument changes mid-campaign get their scope recorded at ruling time.
2. **Registers that announce state lose to registers that answer the player's question.** `RING REVEALED` was ratified, implemented, reviewed, and tested — and died the day Eric played it, because it displaced "when do I need to move?" (amendment 26: continuous `RING CLOSES IN m:ss`, reveal carried by the on-water telegraph alone). On-paper grammar review cannot catch this class; the live-play loop has now caught something in both epics since it became the official mechanism. Working as designed — but HUD copy proposals should be pre-checked against "what question is the player asking at this moment?"
3. **Story sizing creep, four for four:** every spec carried `[oversized]` (3-1 also `[multiple-goals]`). The zero-high outcome softens it, but the flag has fired in every epic since 0.
4. **Cycle-numbering/VERSION races between parallel dev-auto cycles** (3-2 authored as 0.17.32, landed 33; cycle 34 authored as 32, renumbered; cycle 38 authored against unmerged PR #83). Conflicts stayed trivial, but it is recurring friction in every parallel window — worth watching, not yet worth tooling.
5. **Literal control bytes in source** (NUL in hud.ts, patched; pre-existing 0x01 in results.ts, ledgered) make files read as binary to grep — a quiet hazard class the 3-3 review named.

## Key Insights

1. **Match length was the economy fix, confirmed end-to-end:** picks p50 12.0 exactly at closure with zero XP-dial changes — Epic 2's headline finding ("match length, not XP dials, owns the picks band") proven by the timeline alone.
2. **Harness honesty caveats held their weight:** lethal lengths as lower bounds, pacifist caps as structural, the endgame pilot as a modeling instrument — every evidence doc led with them, and the live playtest slotted in exactly where the caveats predicted (humans between the lethal floor and pacifist ceiling).
3. **The derivation doctrine scales:** deriving tunables from other tunables (radar, terminal ring, litRadius) plus constraint tests is proving to be the cheapest anti-drift tool the project has.
4. **Live-play data has a coverage boundary too:** ~10 under-full matches ratified the rhythm but never reached 12:00 — the terminal ring is still human-unverified. Evidence coverage (instrument AND human) should be stated per-claim, not per-epic.
