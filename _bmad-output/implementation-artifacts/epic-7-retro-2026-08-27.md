## 2. Successes

- **The editing surface (7-5).** Printing the shipped 33 card lines with real base→max numbers let Eric author the entire boon catalog himself (7-5-decks.md) — the project's cleanest authority transfer. "An implementer may not invent a mechanic here" held all epic.
- **The fill-rate reframing (7-1, amendment 5).** Measured proof the client is fill-rate bound, not entity bound — three prior retrospectives had asked the wrong question. `powerPreference` alone was worth ~4×. The instrument was the work (amendments 10/11/13 corrected the harness before any number was trusted).
- **Verb-flag retooling (amendment 21).** Converting doctrine enums to independent flags is what made exclusivity deletable at all, and it exposed a real latent both-sides bug (`markZoneEffects` else-if).
- **Two-axis bot policy (amendment 32, cycle 120).** `EquipmentTactic` travels with the weapon; fixed a structurally wrong hull-keyed table.
- **The one-dial assist split (amendment 44, cycle 129).** The spec's encounter-gap machinery was proven redundant and never shipped — simplification by proof.
- **The release gate itself (131).** Both long-standing flakes fixed (making `npm run check` trustworthy again), solo-create throttle with a discriminating regression test, loadTest.mjs built and passing; cycle 131 alone closed six ledger entries.
- **Cycle 127's staging environment** (feature → development → manual QA → main) — the QA gate the release depended on.
- **Perception-invariant discipline held.** Declared exceptions stayed at exactly six all epic; 7-5's jamming fakes needed a carve-out in the *tests'* stronger claim, never the invariant.

## 3. Challenges

- **Design converges by Eric playing the build, not by the pipeline.** ≥10 distinct "Eric saw it live and struck it" cases in three flavors: copy rejected on sight (7-3 LLM tells, the version register, ARMOR, the palette escalation), mechanics replaced after play (the broadside model was redone **four times** after 7-5 shipped it: cycles 113/114/115/130), and invented scope struck (the staging load spike — amendment 46: *"Since when did I ever ask you to do this?"*). **Accepted at this retro as the working loop, not a defect** — the pipeline front-loads correctness, not taste. Empirical rate: **~3 correction cycles per feature story** — a planning input for the next epics, not a fix target.
- **Underestimated complexity concentrated in 7-4 and 7-5.** The consent stack superseded its own design twice within hours (amendments 14→16→18); 7-5 needed two waves, two plan docs, a perception carve-out, and a ~10-cycle correction tail (cycles 110–125 are almost entirely 7-5 aftermath).
- **The flaky gate cost ~20 cycles of trust.** `radarHeatmap.test.ts` (flaky since ≤cycle 110) + the 500ms map budget trained re-run-until-green — "the habit by which a genuine regression eventually rides through." Fixed only at 131.
- **Vacuous-test residue after deletions.** Deliberate test retirement (intel-range, 7-5's deletions) leaves properties the suite can no longer falsify (eighths-ladder ordering now tested at one stack level) — ledgered so it isn't mistaken for coverage, but the residue accumulates.
- **The record system showed merge-time drift.** Branch-local cycle stamps survived as duplicate rows; the A32/A33 amendment headers still carry stale cycle numbers.

## 4. Key Insights

1. **Give Eric an editing surface, not a proposal.** The catalog rewrite worked because it printed facts to edit against; the palette escalation (A36→A37) failed first because the fix targeted the wrong lever (hue, when the scatter was lightness) — measurement before mechanism, then hand the decision over with real numbers.
2. **Budget the correction tail.** Stories ship in one cycle; taste lands over ~3 more. The interstitial cycles are the design process, not overhead.
3. **A flaky gate is worse than no gate.** It trains the exact habit that lets regressions through. Flakes are P1 the day they appear, not cycle-20 cleanup.
4. **Deletions need a falsifiability audit.** When a card/feature deletion retires tests wholesale, record which properties became unfalsifiable — done this epic, keep doing it.
5. **Fixing an instance ≠ fixing a mechanism** (epic-6 lesson, still not mechanized): cycle 126 found five more stale spec statuses and fixed them by hand again.
