## 4. Key Insights

1. **A test must guard a contract of the thing under test.** Vocabulary, copy strings, wall-clock timing and geometry standing in for a perf claim are not contracts; each such test is debt that breaks for unrelated reasons. (Written into project-context.md with this retro.)
2. **Planning artifacts carry invented content; the read is Eric's.** Seven unruled clauses reached code. The agent-side complement: a spec clause with no Eric ruling behind it is marked as such, never presented as settled.
3. **The correction loop is the design process, and it runs post-story.** Epic 8 inverted Epic 7's ratio (23:12 vs 7:22) because corrections batched after 8-22 rather than per story. Both shapes work; the "budget ~3 correction cycles" sizing item was never applied and is retired.
4. **Flags nobody acts on are debt too.** Twelve "follow-up review recommended" flags with zero follow-ups is the Epic 2 lesson (18 waived flags) repeating.
5. **Fixing an instance ≠ fixing a mechanism** (Epics 6 and 7, still not mechanized): spec frontmatter was again consistent by hand, 23 times; the deferred-work triage is now five epics carried.
