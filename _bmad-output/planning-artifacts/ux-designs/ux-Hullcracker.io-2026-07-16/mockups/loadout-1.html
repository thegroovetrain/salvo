Loadout — key · value rows, value opens a picker

Eric's shape: one list. Every row is a KEY (the category) and a VALUE (what is set); pressing the value opens a modal listing every option unlocked for that category; pick one and the modal closes with the row updated. A new category — a captain, a starting kit — is one more row. The SPECIAL row (the Shift ability — the key can be reassigned, so the row is not called Shift) has no caret today (fixed per hull) and becomes a picker the day it is a choice. The picker is also the unlock surface (Eric 2026-09-28): a locked option is listed, greyed with the lock and its ⬢ price, and PRESS, THEN CONFIRM on the card unlocks it in place — nothing is locked on day one. Descriptions live in the picker only — a value is glyph · name · caret; the colour value is the swatch and the hue name.

  • Row grammar: KEY (10 px mono phosphor) · VALUE (52 px control: 30 px glyph · 14 px name · caret). No sub-labels, no sub-lines — a description exists only inside the picker (Eric 2026-09-28). Hover lifts the border to silver; the pressed value goes amber while its picker is open.
  • Ship value is the silhouette glyph and the name; the pip scales live on the hull cards inside the SHIP picker assumption.
  • Special value (Eric 2026-09-28: not "Shift" — the key can be reassigned): dashed border, no caret — read-only until it is a choice; no words say so. What the ability does is read in match, not here.

  • Header: LOADOUT (Eric 2026-09-28, "LOADOUT or something" — his working word; the same word names the results modal's end-state block, ratified 2026-09-11: the screen sets the loadout you sail, the results block shows the one you ended with).   • Picker = modal, one per category, opened from the value only. Pick: press a card → the modal closes, the row's value updates, nothing is saved until CONFIRM assumption.
