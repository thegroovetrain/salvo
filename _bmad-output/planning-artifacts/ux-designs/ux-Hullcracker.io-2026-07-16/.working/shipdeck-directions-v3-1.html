Ship select + deck select/edit — three directions

One screen replaces the class layer AND the /decks page: pick the hull, see the deck it will sail with, edit it, buy copies. Contents are the ratified deckbuilder's, verbatim (card + rail, deck column, named-deck dropdown with ✎ ×, lock + price, hull pips, Color Hoist, CONFIRM SELECTION); only the composition differs. Each direction: SIGNED IN (deck NIGHT RUNNER, 39 / 40, editable) and ANONYMOUS (STARTER DECK, read-only, tagged OPEN — ERIC). The home no longer carries DECKS — this screen is the only door.
