Three complete compositions, same identity, palette and type, differing on where the deckbuilder lives (a page, an overlay, a modal), how a locked line unlocks (always in place, per the Hearthstone / MTG Arena ruling), and how the deck is picked on the class card. Every direction shows the Torpedo Boat starter being edited one card short (39 / 40, TURNING ×2), the seven starter-unowned lines locked with a token price, and the account at LV 7 with 2 tokens. No deck names anywhere; no prose inside any frame; ESC leaves.

THE ARMORY

MTG Arena register, as a full-screen overlay over home.

An overlay in the class layer's own posture — dimmed home beneath, one panel at the 1100 chrome width — so DECKS opens and closes like the class bay and never leaves the port. Density comes from icon tiles that only become the full card on hover, which lets all 29 lines and the whole 40-slot deck sit on one 768 screen without scrolling.

C

THE MANIFEST

List-first, as a modal at the chrome width.

No grid and no second card grammar: one scrolling list of the 29 lines with a bounded stepper on each row is the least UI that can express a 40-card deck under two rules. It is also the cheapest to build and the cheapest to keep correct, because every legality signal lives on the row it belongs to.
